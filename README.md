# ChatMe - Encrypted Peer-to-Peer Chat

ChatMe ialah aplikasi sembang peribadi berasaskan pelayar web (*browser-based*) tanpa pangkalan data pelayan. Semua sambungan menggunakan perhubungan terus Peer-to-Peer (WebRTC) melalui PeerJS.

## 🔒 Ciri-Ciri Keselamatan & Utama

- Penyulitan Hujung-ke-Hujung (E2EE): Mesej teks dan gambar disulitkan menggunakan AES (CryptoJS) sebelum dihantar.
- Tiada Storage Pelayan: Mesej tidak lalu pada pelayan pusat atau disimpan dalam mana-mana database.
- Penghantaran Gambar: Menyokong penghantaran imej yang disulitkan terus kepada penerima.
- Buku Kontak Tempatan: Simpan dan urus senarai kontak di peranti anda sendiri.

## 🚀 Cara Penggunaan

1. Buka index.html pada pelayar web atau layari menerusi GitHub Pages.
2. Salin ID Peranti anda dan berikan kepada rakan anda.
3. Masukkan ID Rakan pada kotak input dan tekan Sambung.
4. *(Disyorkan)* Anda dan rakan anda memasukkan Kunci Penyulitan (Password Sembang) yang sama untuk membolehkan penyulitan mesej & gambar.

## 🛠️ Muat Naik ke GitHub Pages

1. Cipta *Repository* baharu di GitHub.
2. Muat naik fail index.html dan README.md.
3. Pergi ke Settings > Pages di GitHub repository anda.
4. Di bahagian Build and deployment, pilih cabang main (atau master) dan tekan Save.
5. Pautan Web App anda sedia digunakan secara percuma!
